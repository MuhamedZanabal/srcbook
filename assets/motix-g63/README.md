# Motix G63 Web Assets

Static delivery branch for the validated Mercedes-AMG G63 exterior GLB assets used by the Motix Luxury Cars AppDeploy showroom.

- Source package: `G63_Exterior_Hero_Asset(1).zip`
- Desktop: `G63_LOD1_Web.glb`
- Mobile: `G63_LOD2_Mobile.glb`
- Units: metres
- Coordinate authority: +X front, +Y left, +Z up
